# Medicure

Medicure is a healthcare and pathology management project designed to provide users with healthcare-related information and diagnostic support.

## Features
🏥 Healthcare and emergency-care information
🧬 Disease prediction module
🔬 Pathology-related functionality
📍 Nearby hospital information
💻 User-friendly web interface
## Project Structure

├── disease-predictor/    # Disease prediction module
├── emergency-care/       # Emergency care features
└── ...

Machine Learning
